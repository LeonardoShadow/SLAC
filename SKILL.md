# Skills y Enfoque Técnico Requerido

*   **Blazor Web App (.NET 9):** Debes dominar la separación entre componentes SSR (para el flujo ultraligero del estudiante) y componentes interactivos de servidor (para el dashboard del docente)[cite: 4].
*   **PostgreSQL / Supabase:** Habilidad para generar migraciones SQL crudas, con énfasis en optimización, índices por `(institucion_id, lista_id)` y triggers/RLS[cite: 4].
*   **Redis:** Experiencia implementando llaves con TTL para estados efímeros (vigencia del QR) y el patrón Pub/Sub para actualizar el contador de presentes en la pantalla del docente usando SignalR[cite: 4].
*   **Criptografía en .NET:** Capacidad para generar y validar JWTs y tokens propietarios usando `System.Security.Cryptography.ECDsa`[cite: 4].
